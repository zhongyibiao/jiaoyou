## 四、数据库设计

### 4.1 核心表结构

```sql
-- 用户表
CREATE TABLE users (
    id              BIGSERIAL PRIMARY KEY,
    phone           VARCHAR(20) UNIQUE,
    password_hash   VARCHAR(255),
    status          SMALLINT DEFAULT 1,  -- 1正常 2禁用
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

-- 资料表
CREATE TABLE profiles (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT REFERENCES users(id),
    nickname        VARCHAR(50),
    avatar_url      VARCHAR(500),
    gender          SMALLINT,            -- 1男 2女 3未知
    birthday        DATE,
    bio             VARCHAR(500),
    location        GEOMETRY(Point, 4326), -- 经纬度
    last_active_at  TIMESTAMP,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 照片表
CREATE TABLE photos (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT REFERENCES users(id),
    url             VARCHAR(500),
    sort_order      SMALLINT DEFAULT 0,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 兴趣标签表
CREATE TABLE interests (
    id              BIGSERIAL PRIMARY KEY,
    name            VARCHAR(50) UNIQUE,
    category        VARCHAR(50)
);

-- 用户兴趣关联
CREATE TABLE user_interests (
    user_id         BIGINT REFERENCES users(id),
    interest_id     BIGINT REFERENCES interests(id),
    PRIMARY KEY (user_id, interest_id)
);

-- 滑动记录表
CREATE TABLE swipes (
    id              BIGSERIAL PRIMARY KEY,
    swiper_id       BIGINT REFERENCES users(id),
    swiped_id       BIGINT REFERENCES users(id),
    action          SMALLINT,             -- 1喜欢 2拒绝
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 匹配表
CREATE TABLE matches (
    id              BIGSERIAL PRIMARY KEY,
    user_a_id       BIGINT REFERENCES users(id),
    user_b_id       BIGINT REFERENCES users(id),
    created_at      TIMESTAMP DEFAULT NOW(),
    UNIQUE(user_a_id, user_b_id)
);

-- 消息表
CREATE TABLE messages (
    id              BIGSERIAL PRIMARY KEY,
    match_id        BIGINT REFERENCES matches(id),
    sender_id       BIGINT REFERENCES users(id),
    content_type    SMALLINT,             -- 1文字 2图片 3表情
    content         TEXT,
    read_at         TIMESTAMP,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 动态表
CREATE TABLE moments (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT REFERENCES users(id),
    content         TEXT,
    images          JSONB,
    likes_count     INT DEFAULT 0,
    comments_count  INT DEFAULT 0,
    created_at      TIMESTAMP DEFAULT NOW()
);
```

### 4.2 索引策略

```sql
-- 滑动查询优化
CREATE INDEX idx_swipes_swiper ON swipes(swiper_id, created_at DESC);
CREATE INDEX idx_swipes_swiped ON swipes(swiped_id);

-- 位置查询 (PostGIS)
CREATE INDEX idx_profiles_location ON profiles USING GIST(location);

-- 匹配查询
CREATE INDEX idx_matches_users ON matches(user_a_id, user_b_id);

-- 消息查询
CREATE INDEX idx_messages_match ON messages(match_id, created_at DESC);
```

## 五、非功能需求

### 5.1 性能目标

| 指标 | 目标值 |
|------|--------|
| API响应时间 | p99 < 200ms |
| 日活支持 | 10万+ |
| 同时在线 | 1万+ |
| 消息送达 | < 1s |
| 滑动响应 | < 100ms |

### 5.2 安全需求

- **传输加密**: HTTPS + TLS 1.3
- **数据加密**: 敏感字段AES加密
- **接口防护**: 限流、防爬、签名验证
- **内容安全**: 消息审核、敏感词过滤
- **合规**: 个人信息保护法、GDPR

### 5.3 运维需求

- **监控**: Prometheus + Grafana
- **日志**: ELK Stack
- **告警**: 业务异常、接口错误率
- **容灾**: 多可用区部署、自动切换
